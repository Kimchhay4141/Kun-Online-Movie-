## 🔐 **RBAC Management**

### **To Manage Roles:**

Click **"Manage Roles"** button on dashboard

OR go directly to:
```
http://localhost:8000/admin/roles
```

**Features:**
- ✅ View all roles (5 roles)
- ✅ Create new roles (blue button)
- ✅ Edit roles (yellow button)
- ✅ Delete roles (red button)
- ✅ Assign permissions to roles
- ✅ See user counts per role

### **To Create a New Role:**

1. Click **"Create Role"** button
2. Enter role name (e.g., "Editor")
3. Enter description
4. Check permissions from these groups:
   - 📊 Dashboard (3 permissions)
   - 🎬 Movies (6 permissions)
   - 🎭 Genres (4 permissions)
   - 👥 Users (6 permissions)
   - 🏷️ Roles (4 permissions)
   - 🔒 Permissions (4 permissions)
   - 💳 Payments (3 permissions)
   - 🛡️ Moderation (2 permissions)
   - 📈 Analytics (2 permissions)
   - ⚙️ Settings (1 permission)
5. Click **"Create Role"**

### **To Manage Permissions:**

Go to:
```
http://localhost:8000/admin/permissions
```

**Features:**
- ✅ View all 35 permissions
- ✅ Filter by group
- ✅ Create new permissions
- ✅ Edit existing permissions
- ✅ Delete unused permissions
